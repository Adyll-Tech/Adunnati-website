# ADUNNATI Website

A responsive, single-page HTML/CSS/JavaScript recreation of the supplied visual reference.

## Start

Open `index.html` in a browser. For local development, you can use VS Code Live Server or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — full semantic page markup
- `styles.css` — layout, colors, graphics, breakpoints
- `script.js` — mobile menu, testimonial carousel, copyright year
- `assets/design-reference.png` — original supplied design reference

## Notes

The photographic images are sourced from Unsplash via remote URLs, so an internet connection is needed for those images and Google Fonts. The hero scene and product/device mockups are recreated primarily with CSS; they are approximations rather than the exact original 3D assets. The portfolio metrics and testimonials are placeholders copied/adapted for demonstration, not verified claims. Replace brand photographs, stats, contact address and project details before publication. Buttons labeled with contact actions scroll to the contact footer, and the Let's Talk CTA opens an email draft.
